# Free Beta Onboarding Kit

Prepared: 2026-10-18
Owner: Founder
Status: Materials ready; outreach and real-operator acceptance pending

## Start Here

1. Select real prospects using [the recruiting tracker](recruiting-tracker.md).
2. Personalize [the invite](invite-copy.md); review it before sending.
3. Run [the 20-minute session](onboarding-playbook.md).
4. Collect replies using [the feedback process](feedback-process.md).
5. Review the first week's activation and decide what needs fixing.

Website: https://www.afterservice.app
Signup: https://dash.afterservice.app/sign-up
Sign-in: https://dash.afterservice.app/sign-in

## Current Beta Boundaries

- Free early access; no credit card required. Paid plans are planned after beta.
- Email/password and Google sign-in passed production browser acceptance on
  2026-10-19. Operators may choose either method.
- Use phone contact logging for the first workflow. The operator makes their
  own call, then records it. afterservice does not place the call.
- In-app email delivery has not passed production acceptance and is currently
  blocked by Trigger credits. Keep it out of the guided first session.
- Customer SMS/WhatsApp automation and self-onboarding are future work.
- Daily overdue status processing changes board state; it sends no messages.
- Desktop/mobile production browser acceptance passed on 2026-10-19. Physical
  Android install-dialog acceptance remains pending; use the web app without
  promising native installation.

## Launch Checklist

- [x] Invite copy and short follow-up drafts prepared.
- [x] Founder session script and operator quick start prepared.
- [x] Feedback reply channel, triage rules, and capture template defined.
- [x] Recruiting criteria and activation tracker prepared.
- [ ] Founder adds five real prospects and confirms the original reply channel.
- [ ] Send individually reviewed invites; no outreach has been sent by this kit.
- [ ] Watch one real operator complete the workflow without intervention.
- [ ] Onboard five workspaces; observe three complete a real follow-up.

Prepared documents do not establish mailbox monitoring, recruitment, activation,
or customer outcomes. Record those only after they happen.
